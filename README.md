A **full-stack Student Management System** built with React, Node.js + Express, and MongoDB.
Designed using core **C++ OOP principles** translated into a modern web architecture:
- **Encapsulation** → Mongoose models with validators
- **Modularity** → Separate controllers, routes, and components
- **Abstraction** → API layer hides database logic from the UI
- **Composition** → Enrollment model links Student ↔ Course
- **Menu-Driven Interface** → Sidebar navigation dispatching to functional modules
